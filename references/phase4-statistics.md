# Phase 4: 统计分析计划 + 不足与展望

## 目标

1. **统计分析计划 (SAP)**：针对每个终点预先指定分析方法
2. **局限性目录**：诚实面对研究的不足，并提出缓解策略
3. **未来方向**：这项研究完成后，下一步是什么？

---

## 执行步骤

### Step 1: 统计方法匹配

基于 Phase 3 的研究设计 + 终点定义，为每个分析场景匹配统计方法：

#### A. 基线特征分析
- 正态连续变量 → mean ± SD + t-test / ANOVA
- 非正态连续变量 → median (IQR) + Mann-Whitney / Kruskal-Wallis
- 分类变量 → n (%) + chi-square / Fisher exact

> **判定逻辑**：样本量 < 100 或 Phase 2 文献中同类变量用非参数检验 → 默认非参数

#### B. 主要分析（Primary Analysis）

| 结局类型 | 效应指标 | 分析方法 |
|---------|---------|---------|
| 连续变量（两组） | Mean difference (95% CI) | t-test / ANCOVA |
| 连续变量（多组/重复测量） | Mean difference | Repeated-measures ANOVA / Mixed model |
| 二分类变量 | OR / RR / RD (95% CI) | Chi-square / Logistic regression |
| 生存数据 | HR (95% CI) | Log-rank test / Cox regression |
| 计数数据 | Rate ratio | Poisson / Negative Binomial |

#### C. 调整分析
- 如果基线不均衡 → 调整哪些变量？（预先指定）
- 多变量回归模型的选择：Logistic / Cox / Linear → 取决于结局类型

#### D. 亚组分析（预先指定，≤5个）
- 列出每个亚组变量 + 分析原理
- 交互检验方法

#### E. 敏感性分析
- 缺失数据处理（LOCF / MI / Complete case）
- 不同分析人群（ITT / PP / AT）
- 非劣效/等效界值变化

#### F. 安全性分析（如 RCT）
- AE/SAE 计数和发生率
- 按系统器官分类 (SOC)
- 与研究药物相关的不良事件

### Step 2: 样本量/功效验证

如果 Phase 3 没有做样本量计算，在这里补充。如果已做，验证：
- 效应量是否合理（与 Phase 2 文献一致）
- 是否考虑了脱落率
- 是否考虑了多重比较校正

### Step 3: 局限性目录

加载 `templates/limitations_catalog.md`，根据研究设计特点自动匹配 6-10 条最可能相关的局限性。

**匹配规则**（示例）：
- 如果是观察性研究 → 自动匹配「残余混杂」「指征混杂」
- 如果是单中心 → 自动匹配「外部效度-人群代表性」
- 如果样本量 < 200 → 自动匹配「统计局限性-样本量不足」
- 如果主要终点是替代终点 → 自动匹配「替代终点 ≠ 硬终点」
- 如果随访 < 1 年 → 自动匹配「随访时间不足」

**输出格式** — 对每个局限性给出：
1. **问题描述**（为什么要担心这个）
2. **对本研究的影响**（可能会导致什么偏差）
3. **缓解策略**（做了什么来减轻 / 未来可以做什么）

### Step 4: 未来方向

基于研究局限性和 Phase 2 的知识空白，提出 3-5 个可行的下一步研究方向：

| 方向 | 研究问题 | 建议设计 | 优先级 |
|------|---------|---------|--------|
| 机制验证 | ... | 基础实验/中介分析 | 高/中/低 |
| 人群扩展 | ... | 多中心/真实世界 | 高/中/低 |
| 长期随访 | ... | 延伸队列 | 高/中/低 |
| 联合干预 | ... | 析因设计 | 高/中/低 |

### Step 5: 输出文件

写入 `<output_dir>/phase4_statistics/`：
- `10_statistical_plan.md` — 完整统计分析计划
- `11_limitations.md` — 不足与缓解策略
- `12_future_directions.md` — 未来研究方向

### Step 6: 用户确认

展示：
1. 主要分析方法的 1 行摘要（"将用 Cox 回归比较两组的心血管死亡风险，HR 及其 95% CI"）
2. 前 3 个最关键的局限性
3. 最有价值的未来方向

**确认话术**：
> 统计分析计划完成。主要分析用 [方法]，核心局限性是 [XX] 和 [YY]。确认后我们生成最终 PPT。

---

## 注意事项

- ✅ 统计方法推荐必须与医学研究设计原则一致（CONSORT/STROBE）
- ✅ 所有方法是建议，实际应用需要统计学顾问审核
- ✅ 不要编造效应量 — 必须来自 Phase 2 文献或用户提供的 pilot data
- ✅ 局限性不是"示弱"，而是证明你理解自己研究的边界
- ✅ 如果用户的研究是 RCT，必须包含 CONSORT 清单中的统计条目
