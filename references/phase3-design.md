# Phase 3: 实验设计路径规划

## 目标

回答学生的核心问题：**我的实验应该怎么做？**

产出一个完整的研究设计方案，包括：研究类型选择、PICO 精化、终点定义、样本量估算、流程图。

---

## 执行步骤

### Step 1: 研究类型推荐

基于 Phase 1+2 的研究问题本质，推荐最合适的研究设计类型。

**决策逻辑**：

| 研究问题类型 | 推荐设计 | 理由 |
|-------------|---------|------|
| 干预效果评价 | RCT | 因果推断金标准 |
| 危险因素/预后分析 | 前瞻性队列 | 观察自然暴露与结局 |
| 罕见病/长潜伏期 | 病例对照 | 效率优先 |
| 患病率/现况调查 | 横断面 | 描述性研究 |
| 诊断方法评价 | 诊断试验 | 灵敏度/特异度 |
| 证据整合 | 系统综述/Meta | 二次研究 |

**推荐输出格式**：
- 首选推荐 + 充分理由
- 次选替代方案（如果首选不可行）
- 不建议的设计 + 原因

### Step 2: PICO 精化

将 Phase 1 的 PICO 草稿转化为操作化定义：

**P (Population)**：
- 诊断标准（引用指南或标准）
- 具体入排标准（年龄、性别、疾病分期、合并症、检验指标阈值）
- 招募来源（门诊/住院/社区/体检中心）
- 预期筛选-入组比例

**I (Intervention/Exposure)**：
- 干预方案细节（药物名称、剂量、频次、给药途径、疗程）
- 或暴露定义标准（吸烟定义：每天≥1支持续≥6个月）
- 对照方案细节
- 合并干预/禁止用药规定

**C (Comparison)**：
- 对照类型（安慰剂/活性对照/标准治疗/历史对照/空白）
- 对照选择的伦理考虑

**O (Outcome)**：
- 主要终点：定义、测量方法、判定标准、判定时间点
- 次要终点清单（≤5个，避免过多）
- 安全性指标（如适用）
- 探索性终点

### Step 3: 终点指标选择指南

**主要终点的黄金法则**：
1. 必须是单一的（ONE primary endpoint）
2. 对应研究目的
3. 可客观测量
4. 临床有意义（不只是统计显著）
5. 在可行的时间内可观察到

**硬终点 vs 替代终点**：
- 硬终点：死亡、心梗、卒中 — 最有说服力
- 替代终点：血压、HbA1c、LDL-C — 需要实验室异常→临床事件的证据链
- 复合终点：合理安排优先级（死亡 > 严重事件 > 轻微事件）

### Step 4: 样本量估算

运行样本量计算：
```
python scripts/sample_size.py <设计类型> --alpha 0.05 --power 0.80 ...
```

**需要提供的参数**：
- 效应量（来自 Phase 2 文献中的类似研究或 pilot data）
- α 水平（通常 0.05）
- 效力 1-β（通常 0.80 或 0.90）
- 预期脱落率（通常 10-20%）
- 两组比例（通常 1:1）

**输出格式**：
| 参数 | 值 | 来源/理由 |
|------|-----|----------|
| 效应量 | ... | 引用自 Phase 2 某文献 |
| α | 0.05 | 常规 |
| 1-β | 0.80 | 常规 |
| 估算样本量 | N=XX/组 | |
| 考虑20%脱落 | N=XX/组 | |
| 总需招募 | N=XX | |
