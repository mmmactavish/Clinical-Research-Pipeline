# 研究设计检查清单

基于 CONSORT 2010（RCT）、STROBE（观察性研究）、PRISMA（系统综述）、STARD（诊断试验）标准整合。

---

## A. 研究基本信息

- [ ] 研究题目明确（包含 PICO 要素）
- [ ] 研究类型已明确（RCT/队列/病例对照/横断面/诊断/系统综述）
- [ ] 注册号（如 ClinicalTrials.gov NCT 号）
- [ ] 伦理审批状态
- [ ] 资助来源声明

## B. 研究设计与方法

### B1. 研究设计
- [ ] 设计类型选择有充分理由（为什么是 RCT 而不是观察性？）
- [ ] 多中心/单中心选择合理
- [ ] 是否设盲？盲法层级（开放/单盲/双盲/三盲）合理

### B2. 研究对象
- [ ] 入排标准明确定义（诊断标准、年龄范围、疾病分期等）
- [ ] 样本量有正式计算（效应量、α、β、预计脱落率）
- [ ] 招募策略可行（来源人群、招募周期、知情同意）

### B3. 干预/暴露
- [ ] 干预方案详细可复现（药物剂量、疗程、给药途径）
- [ ] 对照选择合理（安慰剂/活性对照/标准治疗）
- [ ] 合并用药/干预规定明确
- [ ] 依从性评估方法

### B4. 结局指标
- [ ] 主要终点：单一、明确、可量化
- [ ] 次要终点：数量合理（避免过多导致多重比较问题）
- [ ] 安全性指标：系统收集不良事件
- [ ] 终点判定方法（独立终点委员会？统一标准？）

### B5. 统计方法
- [ ] 主要分析人群定义（ITT / PP / AT）
- [ ] 主要分析方法预先指定
- [ ] 亚组分析预先定义
- [ ] 缺失数据处理策略
- [ ] 多重比较校正方法
- [ ] 中期分析计划（如适用）

## C. 偏倚控制

- [ ] 随机序列生成方法（如 RCT）
- [ ] 分配隐藏机制（如 RCT）
- [ ] 盲法实施细节（谁设盲？如何保证盲态？）
- [ ] 数据收集标准化（CRF 表设计）
- [ ] 质量控制措施（监查、数据核查）

## D. 可行性与时间线

- [ ] 预计入组周期
- [ ] 预计随访时长
- [ ] 资金/人员/设备资源评估
- [ ] 风险预案（招募慢、脱落高、数据质量问题）

## E. 报告规范

- [ ] CONSORT/STROBE/PRISMA/STARD 流程图
- [ ] 基线特征表格式
- [ ] 主要/次要结果呈现方式（表格/森林图/生存曲线）
- [ ] 不良事件报告格式
