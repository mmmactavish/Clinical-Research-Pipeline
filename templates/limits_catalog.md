# 常见局限性分类目录

用于 Phase 4 自动提示可能的 limitations。根据研究类型和特征，从以下分类中匹配相关条目。

---

## 1. 内部效度威胁 (Internal Validity)

### 1.1 选择偏倚 (Selection Bias)
- [ ] 非随机分组（观察性研究的固有局限）
- [ ] 健康志愿者偏倚（入组者比一般人群更健康）
- [ ] 伯克森偏倚（医院为基础的病例对照研究）
- [ ] 自我选择偏倚（基于问卷/自愿参与的研究）
- [ ] 失访偏倚（脱落率 >20% 或脱落与结局相关）

### 1.2 信息偏倚 (Information Bias)
- [ ] 回忆偏倚（尤其是回顾性收集暴露信息）
- [ ] 测量偏倚（不同中心/不同操作者标准不一）
- [ ] 报告偏倚（主观指标受盲态影响）
- [ ] 诊断偏倚（知晓暴露状态后影响疾病判定）
- [ ] 霍桑效应（被观察本身改变了参与者行为）

### 1.3 混杂 (Confounding)
- [ ] 残余混杂（未测量或测量不准确的混杂因素）
- [ ] 指征混杂（用药患者本身就比不用药者病情重）
- [ ] 时间偏倚（immortal time bias, lead time bias）
- [ ] 通道偏倚（不恰当的对照选择）

## 2. 外部效度威胁 (External Validity)

- [ ] 人群代表性（单一地区/种族/年龄层）
- [ ] 严格入排标准 → 结果不适用于真实世界
- [ ] 三级医院人群 ≠ 社区/基层人群
- [ ] 志愿者效应 → 入组者依从性高于真实人群
- [ ] 时间局限性（诊疗标准已更新）
- [ ] 场所局限性（发达国家 vs 资源有限地区）

## 3. 统计局限性 (Statistical Issues)

- [ ] 样本量不足（特别是亚组分析）
- [ ] 多重比较（未校正的多次检验）
- [ ] 效能不足（II 类错误风险）
- [ ] 缺失数据（分析方法假设可能不成立）
- [ ] 替代终点 ≠ 硬终点
- [ ] 非劣效/等效界值的主观性
- [ ] 期中分析未预先规划
- [ ] 统计方法的模型假设未验证

## 4. 实施局限性 (Implementation)

- [ ] 干预的可行性（成本、设备、培训需求）
- [ ] 依从性问题
- [ ] 交叉/沾染（对照组接受了干预）
- [ ] 随访时间不足以捕捉远期结局
- [ ] 数据质量（电子病历数据的固有缺陷）

## 5. 伦理与监管

- [ ] 安慰剂对照的伦理争议（有标准治疗时）
- [ ] 知情同意的完整性
- [ ] 弱势人群保护（儿童、孕妇、认知障碍）

---

## 使用方式

在 Phase 4 中，根据 Phase 3 的研究设计特点，从此目录中自动匹配 5-8 条最可能相关的 limitations，然后让用户确认和补充。不要机械地列出所有条目。
