# Study Design Checklist

Based on CONSORT 2010 (RCT), STROBE (Observational), PRISMA (Systematic Review), STARD (Diagnostic Test) standards.

---

## A. Study Basic Information

- [ ] Study title clearly states PICO elements
- [ ] Study type specified (RCT/cohort/case-control/cross-sectional/diagnostic/systematic review)
- [ ] Registration number (e.g., ClinicalTrials.gov NCT number)
- [ ] Ethics approval status
- [ ] Funding source declaration

## B. Study Design & Methods

### B1. Study Design
- [ ] Design type justified (why RCT vs. observational?)
- [ ] Multi-center vs. single-center appropriately chosen
- [ ] Blinding: level justified (open-label/single/double/triple blind)

### B2. Study Population
- [ ] Inclusion/exclusion criteria clearly defined (diagnostic criteria, age range, disease stage, etc.)
- [ ] Sample size formally calculated (effect size, α, β, expected dropout rate)
- [ ] Recruitment strategy feasible (source population, enrollment period, informed consent)

### B3. Intervention/Exposure
- [ ] Intervention protocol detailed and reproducible (drug dose, duration, route of administration)
- [ ] Comparator selection justified (placebo/active control/standard of care)
- [ ] Concomitant medications/interventions specified
- [ ] Adherence assessment method defined

### B4. Outcome Measures
- [ ] Primary endpoint: single, clearly defined, quantifiable
- [ ] Secondary endpoints: reasonable number (avoid excessive multiplicity)
- [ ] Safety endpoints: systematic adverse event collection
- [ ] Endpoint adjudication method (independent adjudication committee? Standardized criteria?)

### B5. Statistical Methods
- [ ] Primary analysis population defined (ITT / PP / AT)
- [ ] Primary analysis method pre-specified
- [ ] Subgroup analyses pre-defined
- [ ] Missing data handling strategy
- [ ] Multiplicity adjustment method
- [ ] Interim analysis plan (if applicable)

## C. Bias Control

- [ ] Random sequence generation method (if RCT)
- [ ] Allocation concealment mechanism (if RCT)
- [ ] Blinding implementation details (who is blinded? How is blinding maintained?)
- [ ] Data collection standardization (CRF design)
- [ ] Quality control measures (monitoring, data verification)

## D. Feasibility & Timeline

- [ ] Estimated enrollment period
- [ ] Estimated follow-up duration
- [ ] Resource assessment (funding/personnel/equipment)
- [ ] Risk mitigation plan (slow recruitment, high dropout, data quality issues)

## E. Reporting Standards

- [ ] CONSORT/STROBE/PRISMA/STARD flow diagram
- [ ] Baseline characteristics table format
- [ ] Primary/secondary results presentation format (tables/forest plots/survival curves)
- [ ] Adverse event reporting format
