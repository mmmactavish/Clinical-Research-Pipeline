# PICOS Literature Matrix Template

## Instructions
For each included study, extract information following the PICOS dimensions below. Focus on entries **directly relevant** to your research question.

## PICOS Dimensions

| Dimension | Description | Extraction Focus |
|-----------|-------------|------------------|
| **P**opulation | Study subjects | Sample size, age, sex ratio, key inclusion/exclusion criteria, disease severity |
| **I**ntervention | Intervention/Exposure | Drug dose/duration, surgical approach, diagnostic method, exposure definition |
| **C**omparison | Control group | Placebo/standard care/blank control/before-after self-control |
| **O**utcome | Endpoints | Primary endpoint, secondary endpoints, safety endpoints, follow-up duration |
| **S**tudy Design | Study type | RCT/cohort/case-control/cross-sectional/systematic review, single/multi-center, blinding |
